# What is locked, what is open, and what decides the rest

One page. If a proposed piece of work contradicts this page, the work is wrong or this page
needs a dated amendment — do not quietly proceed.

## Locked now

| Decision | Value |
|----------|-------|
| Buyer | Parents purchasing online for children aged roughly **5–8** |
| Primary launch buyer | The *intentional screen-balancer* — urban, digitally comfortable, wants low-preparation activity with visible learning value |
| Emotional promise | Confident choice → easy screen-light relief → warm cultural connection, **in that order** |
| Product | 20 premium tear-out sheets, light bilingual discovery and creative prompts |
| Position | Creative-learning masterbrand **rooted in** Saudi Arabia — not souvenir publishing, not a worksheet publisher |
| Price test | SAR 39 vs SAR 49, VAT-inclusive; bundle SAR 79 vs 89 |
| Launch | Controlled online release, **15 November 2026** |
| Pilot budget | SAR 22,000 within a SAR 15,000–25,000 ceiling |

## Explicitly not locked

- Final masterbrand name, logo, exact palette, font system — **not before parent language testing**
- Print run quantity — **not before supplier quotes and preorder evidence**
- "Saudi pride" as the hero promise — **only if it beats creative-learning on paid intent**
- Final launch price — chosen by contribution per qualified visitor, not by preference

## The emotional order, and why it is a decision not a description

| Priority | Parent feeling | What creates it | Role of Saudi identity |
|---|---|---|---|
| 1 | Confident | Visible learning value, exact age fit, quality proof | Makes the learning feel relevant |
| 2 | Relieved | Easy, screen-light engagement with little setup | Gives familiar prompts for conversation |
| 3 | Warmly proud | Accurate, contemporary cultural representation | Creates belonging — not a souvenir |
| 4 | Delighted | Giftable design and a child's finished work | Makes Saudi stories collectible |

This ordering is the single most consequential call in the brief, and it is falsifiable.
Cell B of the message test (`04-launch/`) exists specifically to try to break it. If culture-led
messaging wins on qualified intent, the order changes and so does everything downstream.

## The next irreversible decision

**The September validation sprint — not the visual identity, and not the production order.**

Sequence, with the gate that has to pass before the next step is funded:

```
Sept 7–18   Parent interviews + child sessions   → language bank, objections, prototype fixes
Sept 19–30  Survey + landing/message test        → benefit hierarchy, preliminary price
Oct 1–15    Editorial/cultural review + proof    → production-ready files, signed proof
Oct 16–31   Pilot print + store/content          → inventory, real product media, support flow
Nov 1–10    Creator seeding + founder preorder   → reviews, FAQ, 20-order operational check
Nov 15      Public launch                        → replenish only on evidence
```

Gates and thresholds live in `01-validation/05-decision-gates.md`. The rule behind all of them:
**a failed gate changes the plan, it does not get solved with more ad spend.**

## Price decision rule

Use **contribution per qualified visitor** as the primary measure. A higher price is acceptable
only when the extra unit margin more than offsets the conversion loss *and* the return/refund
risk. Preference data does not decide price; the model in `03-economics/` does.

## The five risks that actually kill this

| Risk | Early warning | Mitigation |
|------|---------------|------------|
| Patriotism without repeat use | Traffic spikes at events, weak evergreen conversion | Keep content evergreen; seasonal capsules stay separate from the masterbrand |
| Premium price without proof | High page engagement, weak add-to-cart | Real print video, founder price, clearer specs, value bundle |
| Too-broad age claim | Younger children struggle; older call it babyish | Primary 5–8; challenge icons; age-tiered editions later |
| Cultural cliché or error | Parents comment on narrow or incorrect representation | Independent review + the correction protocol in `claim-discipline.md` |
| Cheap-looking production | Returns, negative reviews, marker bleed | Local proofing, paper/ink tests, smaller first run |

## Standing evidence caveat

The brief is a secondary-research synthesis, not a completed parent survey. Population
statistics use age bands that only partly overlap 5–8; the cited literacy study is a 100-parent
convenience sample skewed to university-educated mothers in the Eastern Province; marketplace
catalog depth proves competition, not demand. **Nothing in this repo should be presented
internally or externally as validated parent demand until the sprint has run.**
