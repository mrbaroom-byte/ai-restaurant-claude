# API surface

Machine-readable contract: [`openapi.json`](./openapi.json) (OpenAPI 3.1, generated by
`pnpm openapi:generate` from the Zod schemas in `src/lib/api/contract.ts`, so it cannot drift).

Auth: session cookie (browser) or `Authorization: Bearer <api-key>` (integrations). Every route is
tenant-scoped by the key/session; there is no cross-tenant route.

| Method | Path | Permission | Notes |
|---|---|---|---|
| POST | `/api/v1/auth/login` | — | password + optional TOTP |
| POST | `/api/v1/auth/logout` | — | |
| GET | `/api/v1/parties` | `contacts.view` | filter, paginate |
| POST | `/api/v1/parties` | `contacts.manage` | |

| GET | `/api/v1/items` | `inventory.view` | barcode lookup via `?barcode=` |
| POST | `/api/v1/items` | `inventory.manage` | |
| GET | `/api/v1/invoices` | `sales.view` | |

| POST | `/api/v1/invoices/{id}/credit-note` | `sales.credit` | full or partial reversal |
| GET | `/api/v1/invoices/{id}/pdf` | `sales.view` | AR/EN, QR, stamp |

| GET | `/api/v1/webhooks` / POST | `settings.manage` | |

Webhooks out: `invoice.created`, `invoice.posted`, `invoice.cleared`, `invoice.rejected`,
`payment.received`, `stock.low`, `payroll.posted`. Signed with `X-Nakhla-Signature`
(HMAC-SHA256 of the raw body, timestamped, 5-minute tolerance).
